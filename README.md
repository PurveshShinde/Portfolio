### ✨ Features
- **Interactive 3D Elements:** Immersive visual experience powered by React Three Fiber and Three.js.
- **Smooth Animations:** Fluid page transitions and component reveals using Framer Motion.
- **Fully Responsive:** Beautifully tailored layouts for all devices using Tailwind CSS.
- **Terminal Easter Egg:** A hidden interactive command-line interface for tech-savvy users.

### 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

#### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

#### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/PurveshShinde/Portfolio.git
   ```
2. Navigate to the project directory
   ```bash
   cd Portfolio
   ```
3. Install dependencies
   ```bash
   npm install
   ```
4. Start the development server
   ```bash
   npm run dev
   ```

### 📁 Folder Structure
```text
src/
├── components/   # Reusable UI components (Navbar, Footer, 3D Canvas, etc.)
├── context/      # React context providers
├── pages/        # Page sections (Home, About, Skills, Projects, Experience, Contact)
├── utils/        # Utility functions and helpers
├── App.tsx       # Main application layout and section routing
├── constants.ts  # Static data (Profile, Skills, Projects, etc.)
└── main.tsx      # Application entry point
```
